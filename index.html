🧳 哪些可以帶上飛機?

✅ 可隨身帶

  • 護照(效期 6 個月以上)、手機、錢包
  • 行動電源:必須手提,不可託運;不建議在機上使用
  • 100ml 以下液體,裝進 1 公升透明夾鏈袋
  • 藥品(附原包裝/處方)、濕紙巾

❌ 不能帶/不能放隨身

  • 超過 100ml 的液體、噴霧、膠狀物 → 需託運
  • 刀具、剪刀、瑞士刀 → 只能託運
  • 行動電源/鋰電池 → 不可放託運行李
  • 打火機規定嚴格,建議不帶,並先查華航最新規定

🏠 回台灣注意

  • 肉類製品(含肉鬆、肉乾)不可帶回台灣
  • 新鮮水果、植物、種子禁止入境
  • 菸酒、免稅額度請依海關規定
⚠️ 行李重量與尺寸請以華航訂位頁面為準,出發前再確認一次。

🛬 第一次自由行:日本入境流程

出發前先做:在「Visit Japan Web」(vjw.digital.go.jp)註冊,填好入境審查與海關申報,截圖 QR Code 備用,過關會快很多。

  1. 下機後跟著「入國審査 Immigration」指標走
  2. 外國人櫃檯:交護照,按指紋、拍臉部照片
  3. 領行李(看螢幕找 CI128 的轉盤)
  4. 海關:出示 Visit Japan Web 的海關 QR Code 或紙本申報單
  5. 走出入境大廳,到免費接駁巴士站,搭往國內線航廈
🚇 福岡機場很小,國際線與地鐵站不在同一棟。依行程記錄,抵達後需到國內線航廈的「福岡空港站」。步行約 5–7 分鐘,國際線航廈也有免費接駁巴士可搭(實際以現場指示為準)。

🛫 最快速的登機方式

  1. 出發前 24 小時:華航官網/App 線上報到,存好電子登機證
  2. 起飛前 3 小時抵達桃園機場(10/24 建議 11:40 前,10/30 福岡建議 17:35 前)
  3. 只帶手提行李可直接過安檢;有託運就找華航櫃檯或自助託運
  4. 安檢:液體袋、電腦、手機拿出,皮帶外套放籃子
  5. 出境檢查後,先確認登機門再逛免稅店
  6. 起飛前 40 分鐘到登機門,登機門可能更改,留意螢幕

🚇 交通與 Visa 卡搭乘

💳 Visa 感應搭福岡市地鐵

  • 福岡市地鐵全 3 線都能直接刷 Visa 感應進出站(空港線、箱崎線、七隈線)
  • 同一張卡、同一天(凌晨 3 點到隔天凌晨 3 點)最高收 ¥640,超過免費
  • 進站、出站必須用同一張卡/同一裝置,不要換卡或換手機
  • 多人同行時,每人要用自己的卡,不能一張卡刷多人

  • 官網首頁有「山頂天氣」,會顯示天氣、氣溫和視野,更新時間也會標出來
